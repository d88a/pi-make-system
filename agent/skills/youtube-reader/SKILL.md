# YouTube Reader

## Когда использовать

Пользователь даёт ссылку на YouTube видео и просит:
- "посмотри это видео"
- "что на этом видео"
- "опиши содержимое"
- "распознай речь в видео"

## Как использовать

### Шаг 1: Извлечь кадры и аудио

```bash
~/.pi/agent/scripts/youtube_extract.sh "https://youtube.com/watch?v=XXXXX"
```

Скрипт вернёт JSON с:
- `frames[]` — массив путей к кадрам
- `transcript` — транскрипция речи
- `title` — название видео
- `duration` — длительность

### Шаг 2: Распознать кадры

Передать кадры image-reader агенту:

```
Распознай что на этих кадрах из видео "{title}":
- Кадр 00:05: {path}
- Кадр 00:15: {path}
- Кадр 00:25: {path}
...

Опиши что происходит в каждом кадре и дай общий обзор видео.

Транскрипция речи: {transcript}
```

### Шаг 3: Компиляция результата

Собрать:
1. Описание каждого кадра (от image-reader)
2. Транскрипцию речи (от Deepgram, если есть)
3. Общий анализ: что происходит в видео

### Шаг 4: Очистка временных файлов

После обработки удалить временную директорию:
```bash
rm -rf /tmp/youtube_extract-*
```

## Параметры

- `frames_per_minute` — сколько кадров в минуту (default: 6)
  - Для быстрых действий (спорт, игры): 12
  - Для лекций/разговоров: 3-4
- `language` — язык речи (default: "ru")

## Ограничения

- Максимум 100 кадров
- Видео > 30 мин — только первые 30 мин
- Для транскрипции нужен Deepgram ключ в search_keys.yaml

## Установка зависимостей

```bash
# yt-dlp
pip install yt-dlp

# ffmpeg (если не установлен)
sudo apt install ffmpeg ffprobe

# jq (для парсинга JSON)
sudo apt install jq
```

## Deepgram API

Ключ добавляется в `~/.pi/agent/secrets/search_keys.yaml`:
```yaml
deepgram:
  api_key: "ваш_ключ"
```

Поддерживаемые языки: ru, en, uk, de, fr, es, и многие другие.
Модель: nova-2 (лучшее качество, поддерживает русский).
