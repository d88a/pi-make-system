Инструкция по импорту

  1. Скачайте JSON файл шаблона
  2. В Elementor перейдите: Templates → Import
  3. Выберите скачанный JSON файл
  4. Шаблон появится в "My Templates"
  5. Создайте новую страницу и импортируйте шаблон
