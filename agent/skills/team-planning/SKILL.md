# Team Planning — Планирование команды

Этот навык помогает спланировать команду для выполнения задачи. 
Применяется **после** того как задача обсуждена с владельцем и 
все вопросы прояснены.

## Процесс

### Шаг 1: Декомпозиция задачи
Разбей задачу на подзадачи. Для каждой определи:
- Что нужно сделать (ожидаемый результат)
- Какой тип мышления нужен:
  - **Аналитический** — поиск паттернов, анализ данных → data-analyst
  - **Конструкторский** — написание кода → coder
  - **Критический** — проверка кода/логики → code-auditor, logic-auditor
  - **Предметный** — трейдинг, математика → trader-analyst, mathematician
  - **Исследовательский** — поиск информации → researcher
  - **Визуальный** — распознавание картинок → image-reader
- Какой объём данных задействован
- Насколько подзадачи независимы друг от друга

### Шаг 2: Выбор количества сотрудников

**Ensemble из 3 аналитиков** (параллельно, одинаковые данные):
- Высокая неопределённость
- Поиск "дыхания рынка" — качественные паттерны
- Первый проход анализа
- Критически важные выводы

**Один аналитик**:
- Стандартная задача с понятными данными
- Проверка конкретной гипотезы
- Итерация после ensemble

**Coder + Auditor**:
- Любое написание production кода
- Кодер пишет → аудитор проверяет

**Математик**:
- Нужна статистическая оценка
- Расчёт рисков
- Проверка win rate

### Шаг 3: Порядок выполнения
- Что можно **параллельно** → parallel mode в subagent
- Что **последовательно** → chain mode в subagent
- Где нужны **контрольные точки** для согласования с владельцем

### Шаг 4: Согласование с владельцем
**Перед началом работы** покажи план:
- Какие роли привлекаются
- Сколько сотрудников на каждой роли
- Порядок выполнения
- Ожидаемый результат

Дождись подтверждения перед запуском.

(с согласованием с владельцем).

## Пример плана

```
Задача: Найти точки разворота на RAVE/USDT и общие паттерны

План:
1. [PARALLEL] 3 × data-analyst — каждый независимо анализирует 
   сырые данные, ищет точки разворота
2. [SEQUENTIAL] data-analyst — синтез результатов, выделение 
   общих паттернов
3. [SEQUENTIAL] mathematician — статистическая проверка, win rate
4. [SEQUENTIAL] coder — реализация фильтра (если паттерны подтверждены)
5. [PARALLEL] code-auditor + logic-auditor — проверка реализации

Итого: 7 запусков суб-агентов, 2 параллельных этапа
```
