# Composition Pipeline Test

Purpose: verify the new Design Brief → Composition Plan → UI-Coder contract on a small, content-clear landing page.

This fixture deliberately tests composition rather than style variation. The expected result must be structurally distinguishable from the canonical centered hero → cards → CTA pattern while keeping the content immediately understandable.

## Test brief

**Project:** Северный Дом
**Niche:** residential construction
**Audience:** people planning to build a permanent country house
**Primary message:** «Строим дом для жизни, а не для отчёта»
**Proof:** строительство под ключ; фиксированный срок 8 месяцев; гарантия 5 лет
**CTA:** получить расчёт проекта

## Required composition

- Hero: full-bleed finished-house photography, headline anchored bottom-left, short proof line, one primary CTA.
- After hero: compact proof strip, not cards.
- Process: asymmetric split with one dominant image and concise numbered steps.
- Projects: editorial image-led gallery with unequal image sizes.
- Trust: one strong testimonial block, visually quiet.
- Final CTA: contained contact block with generous whitespace.

## Forbidden

- centered generic hero;
- three equal feature cards directly after hero;
- invented claims, statistics, prices or project details;
- decorative mechanisms that compete with the message.
