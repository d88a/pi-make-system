# Acceptance criteria

The test is successful only if the generated page visibly follows the composition plan.

1. Hero is not centered generic; image is dominant and content sits bottom-left.
2. Proof is a compact strip, not three generic cards.
3. Process uses an asymmetric split.
4. Projects use unequal editorial image composition.
5. Section density changes across the page.
6. No invented content or placeholder construction imagery.
7. A viewer can understand the offer and primary CTA without knowing the plan.
8. Responsive layout preserves content order and hierarchy.

Style changes alone (font/color/radius) do not count as passing the test.
