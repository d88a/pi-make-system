# PLAN — Усадьба «Барышня-крестьянка»

**Проект:** Лендинг проекта возрождения усадьбы (single-page, 9 блоков)
**Финальная цель:** WordPress + Elementor Pro на хостинге заказчика
**ТЗ:** `ТЗ на сайт 2026 (1).docx`

---

## 📐 Параметры задачи (3 оси)
- **Input:** Description + Brand (детальное ТЗ, палитра и шрифты заданы)
- **Fidelity:** Guided
- **Scope:** Single-page

## 🎨 Дизайн (кастомная «дворянская» тема)
- Палитра: зелёный (герб) / терракотовый (храм) / золото (декор) / бежевый (фоны)
- Шрифты: Playfair Display (H1-H3) + Open Sans (текст), line-height 1.5
- Мобильный текст ≥ 16px, полная адаптивность
- Текстуры под старину, винтажные рамки, сдержанный классический стиль

## 🧱 Структура (9 блоков, сверху вниз)
1. **Хедер** — логотип + кнопка «Связаться с нами», sticky
2. **Hero** — фото усадьбы, H1, подзаголовок, текст, кнопка «Узнать подробнее» (скролл)
3. **О проекте** — «Дорогие друзья!» + логотипы партнёров (placeholder)
4. **Историческая ценность** — «Почему это место особенное?» + портреты/коллаж
5. **Наше наследие сегодня** — сетка 3 колонки (парк / архитектура / соседи)
6. **Наша миссия** — текст + панорамное фото
7. **Кого мы ищем** — для инвесторов, список, примечание в рамке
8. **Как познакомиться** — текст + Яндекс.Карта (iframe) + кнопка «Записаться на экскурсию / встречу»
9. **Контакты/футер** — Островский О.В., +7 903 904 90 90, zed900@mail.ru, соцсети (placeholder), форма (Имя + Телефон/Email → Kremlmaskva@mail.ru)
