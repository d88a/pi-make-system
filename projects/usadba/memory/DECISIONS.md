# DECISIONS — Усадьба «Барышня-крестьянка»

## Проблемы и решения (хронология)

### Проблема 1: Несовместимость версий Elementor
**Симптомы:** Fatal error `Undefined constant ALERT`, страница не грузится
**Причина:** Hello Elementor 3.4.9 (новая) + Elementor 3.14.1 (старый) — несовместимость
**Решение:** Обновить Elementor до 4.2.3 ИЛИ откатить Hello Elementor до 2.7.1
**Итог:** Elementor 4.1.3 + Hello Elementor 2.7.1 — стабильная пара

### Проблема 2: Программная запись _elementor_data не рендерится
**Симптомы:** JSON в базе есть, страница пустая
**Причина:** Формат typography — вложенный объект `typography: {font_family: ...}` вместо плоских ключей
**Решение:** `typography_font_family`, `typography_font_size` и т.д. (плоские ключи с префиксом `typography_`)
**Итог:** typography_typography: "custom" + плоские ключи

### Проблема 3: Inline-стили в text-editor ломают рендеринг
**Симптомы:** Страница пустая при добавлении style="..." в text-editor
**Причина:** Elementor 4.2+ контейнеры не принимают inline-стили в editor
**Решение:** В format container — не использовать inline-стили. В format section+column — РАБОТАЮТ
**Итог:** В section+column формате inline-стили работают

### Проблема 4: Copy-Paste не работает между сайтами
**Симптомы:** "функции относящиеся к скопированному элементу не включены"
**Причина 1:** Разные версии Elementor (4.2.3 vs 4.1.3)
**Причина 2:** `container_type: "flex"` не поддерживается в 4.1.3
**Причина 3:** Copy-Paste требует доступности обоих сайтов друг другу
**Решение:** Откатить локальный Elementor до 4.1.3, использовать section+column формат
**Итог:** Copy-Paste НЕ использовать. Перенос через JSON-шаблоны.

### Проблема 5: Импорт шаблона "Invalid Content In File"
**Симптомы:** Ошибка при импорте JSON
**Причина:** Неправильный формат — массив элементов вместо `{"content": [...]}`
**Решение:** `{"content": [...элементы...], "title": "...", "type": "section"}`

### Проблема 6: Шаблон импортируется но пустой
**Симптомы:** Импорт успешен, но контента нет
**Причина:** `$$type` формат (4.2+) не распознаётся Elementor 4.1.3
**Решение:** Использовать простые строки для title (без $$type), section+column вместо container

### Проблема 7: Контейнеры (flex/grid) не поддерживаются у заказчика
**Симптомы:** У заказчика Elementor 4.1.3 без flex-контейнеров
**Причина:** Старая сборка 4.1.3 до внедрения flex-контейнеров
**Решение:** ВСЕГДА использовать section + column (классический формат)

### Проблема 8: Внешний CSS не виден в редакторе
**Симптомы:** На фронте красиво, в редакторе пусто
**Причина:** Стили через external CSS, а не через нативные настройки Elementor
**Решение:** typography_* + text_color + align + background_color через нативные настройки. CSS только для декора (роверлей, рамка, divider-линии)

## Формат переноса (ИТОГОВЫЙ)

1. **Сборка:** section + column (классический формат)
2. **Экспорт:** `{"content": [...], "title": "...", "type": "section"}`
3. **Импорт:** Elementor → Templates → Import
4. **Site Settings:** глобальные цвета + шрифты вручную
5. **CSS:** декоративный CSS в Custom CSS (Elementor Pro)

Локальная сборка (Docker) → JSON-шаблон → импорт на хостинг заказчика
