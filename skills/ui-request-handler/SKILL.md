# ui-request-handler SKILL.md

## Описание
Обрабатывает все запросы о дизайне (редизайн, изменение блока, перемещение элемента) и автоматически запускает make-ui flow.

- "смени"

- "элемент"

- "внешний вид"

- "похожий на"
- "в стиле"
- "подобно"
- "как у"
- "смотри"
- "смотрите"

## Протокол
1. Проверить, содержит ли запрос ключевые слова.
2. Если да → запустить `make-ui` с описанием.
3. Если нет → продолжить как обычно.

## Примеры
- "Передвинь кнопку вниз" → запуск make-ui
- "Измени цвет карточки" → запуск make-ui
- "Сделай лендинг" → запуск make-ui
- "Внешний вид сайта должен быть чистым" → запуск make-ui
- "Стиль должен быть в духе Apple" → запуск make-ui
- "Анимация при наведении должна быть плавной" → запуск make-ui
